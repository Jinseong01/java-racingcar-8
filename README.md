# java-racingcar-precourse

## 기능 목록

- ### 입출력 기능
  - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`의 형식으로 안내 메시지를 출력한다.
  - 사용자로부터 쉼표(,)로 구분된 자동차 이름 문자열을 입력받는다.
  - `시도할 횟수는 몇 회인가요?`의 형식으로 안내 메시지를 출력한다.
  - 사용자로부터 시도 횟수를 입력받는다.
  - `실행 결과`의 형식으로 안내 메시지를 출력한다.
  - 각 시도마다 `{자동차 이름} : {이동 결과}`의 형식으로 결과를 출력한다. 
    - 이동 결과는 이동 거리만큼 `-`로 표시한다.
  - 모든 시도가 끝나면 최종 우승자를 출력한다. 
    - 단독 우승 - `최종 우승자 : {자동차 이름}`
    - 공동 우승 - `최종 우승자 : {자동차 이름1}, {자동차 이름2}`

- ### 핵심 기능 (문자열 분리 + 무작위 값 생성 + 경주)
  - 입력받은 자동차 이름들을 쉼표(,) 기준으로 분리한다.
  - 각 시도마다 모든 자동차는 무작위 값(0~9)을 통해 전진 여부를 결정한다.
    - 무작위 값이 4 이상이면 전진한다. 
    - 무작위 값이 3 이하이면 전진하지 않는다.
  - 모든 시도 종료 후, 가장 멀리 이동한 자동차(들)를 우승자로 판정한다.
    - 최대 이동 거리를 찾는다.
    - 해당 거리를 이동한 모든 자동차를 우승자로 선정한다.

- ### 세부 설정
  - 자동차는 최소 2대 이상이다.
  - 시도 횟수는 최소 1회 이상, 최대 100회 이하이다.
  - 쉼표(,) 이외의 문자는 이름으로 인정한다.
    <br>단, 공백 문자열(" ")만으로 이루어진 이름, 앞뒤에 공백이 포함된 이름은 허용하지 않는다.
  - 공동 우승의 출력은 입력 순서대로 출력한다.

- ### 예외 상황
  - 잘못된 입력은 예외(`IllegalArgumentException`) 처리 후, 애플리케이션을 종료한다.
    - 자동차 이름 관련
      - 빈 문자열 또는 공백 문자열을 입력한 경우 (ex. `""` / `" "` / `pobi,,jun` / ` ,pobi,jun`)
      - 이름 앞뒤에 공백이 포함된 경우 (ex. `pobi , woni`)
      - 이름이 5자를 초과한 경우 (ex. `pobiiii,woni`)
      - 이름이 중복된 경우 (ex. `pobi,pobi`)
      - 1대만 입력한 경우 (ex. `pobi`)
    - 시도 횟수 관련
      - 정수가 아닌 값을 입력한 경우  (ex. `""`/ `" "` / `A` / `0.1`)
      - 범위를 벗어난 값을 입력한 경우  (ex. `0`, `101`)
